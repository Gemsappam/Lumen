# Учёт Люмен — Telegram Mini App

Оператор вносит пополнение → инвойсы плантаций (PDF/фото читает AI) → счета за фрахт по AWB →
бот считает себестоимость стебля и присылает `учет.xlsx` с новым листом «Пополнение DD.MM».

## Как считает
1. Курс пополнения = ₽ отправили / $ зачислено. Всё оплаченное из пополнения — по этому курсу.
2. Суммы оплаты $ и ₽ вносит оператор — они берутся как есть, ничего не пересчитывается.
3. ₽ на стебель = цена $ × (₽ оплаты / $ оплаты). Налог, doc fees и прочее в цену стебля не идут.
   Для гортензий — режим «поровну на стебель» (₽ / стебли).
4. Логистика: счёт по AWB (плечо «авиа» или «МСК») делится на все плантации этого AWB по кг
   (разбивка консолидатора), внутри плантации — по кг строк → коробкам → стеблям.
5. Себестоимость = цветок + авиа + МСК. В Excel всё формулами: поменял $ или фрахт — пересчиталось.

## Запуск
```
cp .env.example .env        # заполнить
pip install -r requirements.txt
python -m app.main
```
BotFather: /newbot → токен в BOT_TOKEN; /setmenubutton → URL = WEBAPP_URL.
Нужен публичный HTTPS. Самый дешёвый вариант — бесплатный Cloudflare Tunnel:
`cloudflared tunnel --url http://localhost:8080` (на постоянку — именованный туннель с доменом).
Хостинг: любой сервер, где уже крутится Python-бот, 1 процесс, SQLite — база в `data/`.

Первым делом кинь боту текущий `учет.xlsx` — он станет мастер-файлом, старые листы не трогаются.

## Файлы
- `app/calc.py` — движок себестоимости (без БД, тестируется отдельно)
- `app/excel.py` — лист в формате учёта, живые формулы, блок «ЛОГИСТИКА» и «ПРОВЕРИТЬ»
- `app/ai.py` — распознавание документов (PARSE_MODEL) и AI-проверка пополнения (AUDIT_MODEL)
- `app/api.py` — API + проверка подписи Telegram, доступ только ALLOWED_IDS
- `app/bot.py` — бот: кнопка Mini App, приём PDF/фото → черновики, приём мастер-.xlsx
- `webapp/index.html` — интерфейс оператора
